# 私有协作资料恢复

当前仓库为私有，主分支已包含 159 个规范条文文件、43,813 个条文块和 329 条台账记录。过滤条文说明、被替代和废止条文后，检索池为 28,440 块。数据快照日期为 2026-10-20。

## 直接开始检索开发

下载项目，按 README 安装轻量依赖，然后从 `kb/` 运行：

```sh
python -m tools.check_snapshot
python run_dev.py
```

打开 <http://127.0.0.1:8000>，使用日志中的随机口令。无需模型和密钥即可使用条号直达、关键词检索、书目和条文详情。

`kb/data/runtime-manifest.json` 记录完整条文文件和台账的 SHA256。台账中三处本机绝对路径诊断信息已去除，规范的相对路径和条文正文保持原样。模型能力需要另行配置；本地 `bge-m3` 目录曾缺少权重，换机时请用下载工具重新取得完整模型。

## 获取原件与 OCR 资料

[完整协作资料快照](https://github.com/EXCEED2050/building-code-kb/releases/tag/data-2026-10-20)包含 7 个独立 ZIP，总下载量约 4.11 GB，解压约 4.60 GB，共 4,220 个文件：

| 附件 | 内容 |
| --- | --- |
| `originals-part01.zip` 至 `originals-part03.zip` | 原始规范 PDF、Word 和原始资料压缩包，恢复到项目根目录的 `建筑规范/` |
| `mineru-part01.zip`、`mineru-part02.zip` | 此前 MinerU 解析结果、对应原件、图片及转换文档，恢复到 `MinerU/` |
| `ocr-part01.zip`、`ocr-part02.zip` | OCR 合并 PDF、JSON/Markdown 与图片，恢复到 `kb/data/ocr/` |
| `asset-manifest.json`、`SHA256SUMS.txt` | 资料卷和逐文件校验清单 |
| `README-downloads.txt` | 下载与解压说明 |

这些 ZIP 是独立资料卷，不要把它们按字节拼接成一个大 ZIP。可以只下载需要的卷；要恢复当前全部处理资料则下载全部 7 卷。所有附件放在同一个文件夹，再从项目 `kb/` 运行：

```sh
python -m tools.restore_assets /附件文件夹 --check-only
python -m tools.restore_assets /附件文件夹
python -m src.source_pdf
```

工具会核对 ZIP 和每个解压文件的 SHA256，保留与快照一致的现有文件；同名文件内容不同则停止并报告，不直接覆盖。缺少的资料卷也会报告，方便按需恢复。默认恢复到当前工具所属项目的根目录，可用 `--root` 显式指定另一个项目根目录。

恢复后可测试 PDF 预览，并检查规范编号、实际原件与条文页码是否对应。完整资料已复制不代表 OCR 文字、版本状态、修订记录和所有页码均经过人工验收。

## 没有共享的内容

真实 `.env`、API 密钥、访问口令与签名密钥、模型权重、Chroma 索引、页图缓存、云端 OCR `_cloud/` 作业状态与临时上传片段、系统杂项和旧实现的运行环境未共享。队列可以根据台账与优先级表重新生成。

本仓库及附件含企业标准和内部开发资料，仅向有相应资料使用权限的协作者开放。不要把含完整资料的仓库或附件改为公开。
