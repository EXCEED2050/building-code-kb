## 协作者更新

先提交或备份自己的改动，再拉取主分支，重新 `python -m pip install -e .`。已有大资料可按表移动到新目录，不需要重新下载；同名目标已存在时先比较，不直接覆盖。也可使用新版恢复工具读取原 Release 的 ZIP 和原清单，自动放入新目录。

所有根目录相对 `file_path`、人工核对 PDF 路径与快照清单已同步。已发布 ZIP 的字节和哈希不改，新附件清单用 `archive_path` 保留归档成员旧名。375 个独立 PDF 和 7 个备份 ZIP 的下载链接继续有效，旧 `docs/PDF目录.md` 保留跳转说明。

历史架构图与实施记录包含旧路径和旧进度，保留原文供追溯，不作为当前运行说明。一次性上传工作流已退出主分支；当前 `.github/workflows/ci.yml` 用于自动检查。
