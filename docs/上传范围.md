## 已验证

在独立 Python 3.12 环境安装轻量依赖，使用仅含上传文件的副本验证：

- 首页访问、未登录查询和书目接口返回 401。
- 错误口令被拒绝，正确口令取得 HttpOnly 会话 Cookie。
- 示例检索池为 3 条、1 本；条号直达与关键词查询正常返回 SSE 命中和结束事件。
- 条文详情可访问；无模型密钥时返回不可作答事件，检索仍可使用。
- 退出清除 Cookie，随后受保护接口重新返回 401。
- 上传文本通过 Python 语法检查和凭据扫描；没有实际 `.env` 中的密钥值或本机用户绝对路径。

未重新验证完整真实语料、模型下载/推理、本地或云端 OCR，以及服务器部署。GitHub 上传保存源码和说明，不会自动运行或部署应用。
