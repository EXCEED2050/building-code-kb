# 私有协作上传范围

2026-10-20，仓库已改为私有，并按两人共同开发的用途补齐资料。请保持私有，仅向有相应资料使用权限的协作者开放。

## 主分支

- 应用源码、架构图、运行与协作文档、人工订正和引用提醒表。
- 完整 `data/chunks/`：159 个规范文件、43,813 个条文块；排除被替代、废止及条文说明后，检索池为 28,440 块。
- `data/catalog/catalog.csv`：329 条台账记录；去除了三处本机绝对路径诊断信息，保留规范相对路径。
- `runtime-manifest.json` 和 `asset-manifest.json`：完整条文、台账、原件和 OCR 资料的文件清单、大小及 SHA256。
- `src/building_kb/commands/check_snapshot.py` 和 `src/building_kb/commands/restore_assets.py`：分别核验条文快照、核验并恢复大文件附件。
- `docs/history/项目实施记录.md`：此前方案与实验记录，已替换本机用户路径；历史数量和选型不代表当前状态。
- 原先 16 本公开规范的正文子集仍保留在 `examples/public/`，供开发对比。

## 同仓库的私有下载附件

[2026-10-20 完整协作资料快照](https://github.com/EXCEED2050/building-code-kb/releases/tag/data-2026-10-20)包含 7 个独立资料卷，约 4.10 GB，解压约 4.60 GB，共 4,220 个文件。

原始规范 PDF/Word/资料压缩包位于 `originals` 三卷；MinerU 原件、解析结果和图片位于 `mineru` 两卷；OCR 合并 PDF、JSON/Markdown 和图片位于 `ocr` 两卷。附下载说明、完整文件清单和 SHA256 校验值。恢复方法见 [私有资料恢复](私有资料恢复.md)。

## 排除
