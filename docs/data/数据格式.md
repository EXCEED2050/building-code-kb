# 条文数据格式

应用读取 JSONL，每行一个条文对象，UTF-8 编码。完整字段样例见 `examples/demo/chunks/DEMO.jsonl`，真实公开正文见 `examples/public/chunks/`。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `chunk_id` | 字符串 | 数据快照内唯一标识；含 `#` 等字符时，作为 URL 路径须编码 |
| `std_code`、`std_name` | 字符串 | 规范编号（含版本年）和名称 |
| `version` | 字符串 | 原切条记录的版本标识 |
| `clause_no` | 字符串 | 条文号，不能当浮点数处理 |
| `chapter_path` | 字符串 | 章节上下文，用于展示和关键词索引 |
| `section_type` | 字符串 | 正文、修订或条文说明；公开快照仅收正文 |
| `text` | 字符串 | 条文正文，保留原数值、比较号和单位 |
| `tables` | 字符串数组 | 随条文保存的表格，可能为 HTML |
| `page_idx` | 整数或 null | 原解析 PDF 页码，从 0 开始；展示页码加 1 |
| `is_mandatory` | 布尔 | 强制属性；应结合 `mandatory_basis` 审核 |
| `mandatory_basis` | 字符串 | 强制属性依据，公开快照附官方来源链接 |
| `superseded` | 布尔 | 该块是否已被本地修订记录替代 |
| `status` | 字符串 | 本地台账状态；`待核` 不等于已确认现行 |
| `caveat` | 字符串 | 引用前必须展示的提醒 |

`retrieve.py` 默认过滤 `superseded=true`、`status=废止` 和条文说明；它不会自动到官方平台核对有效性。不要把通过程序筛选等同于通过规范有效性审核。

### 原件核对与校订

条文目录的父目录可放置 `verification.json`。应用读取原始JSONL后，按条文ID和正文/表格/页码内容指纹应用核对记录，原始文件和`status`不变。记录包含原PDF的SHA256、核对页序、差异说明和替换内容。`source_review`表示本次转录对照范围；`answerable=false`的已知问题转录不展示原错值，也不送入模型。源转录变动而指纹不符时，旧校订失效并阻止该条作答。PDF文件指纹留作复核依据，程序不会自动将新PDF页码映射为旧PDF页码。

`mandatory_historical=true`表示强条标记来自历史出版物，不能被页面或模型转述成已确认当前效力。版本发布/修订公告与工程适用性需分别核对。首批结果见[广州试用核对记录](../acceptance/广州试用核对结果-20261022.md)。

公开数据文件由 `src/building_kb/commands/export_public.py` 导出，清单中的 SHA256 校验的是 UTF-8 文件全部字节。`python -m building_kb.commands.export_public --check` 无需下载模型或持有私有语料，可发现文件缺失、意外新增文件、重复条文、编号混入和内容改动。

公开台账的 `file_path` 留空，因为仓库未分发原件；来源使用单独的 `source_url`。配齐原件后应建立自己的台账和路径映射，不要把另一个人的绝对路径写进共享代码。

### 完整PDF与会话快照

`source_documents.json`中的`source_pdf_sha256`对应原定位副本，`sha256`对应完整阅读本，`page_offset`将原副本1起算页序映射到完整本。`parts`记录用于重建完整本的分卷路径与指纹。GB 55037原副本为66页、完整本136页，偏移8页；`page_idx`及逐页预览仍使用原副本，不能直接加8写回JSONL。`building_kb.commands.build_source_documents`只从已登记分卷重建，`building_kb.commands.check_reviews`复核完整本指纹和页序边界。

浏览器当前问答的导出JSON为`version=1`，`rounds`逐轮记录`question`、`answer`、`evidence`（本轮命中条文快照及检索式）、`completed`，`updated_at`为保存时间。最近6轮用于追问上下文，导出保留本组全部已完成或无依据的轮次。它不是服务器日志，不跨设备同步；恢复记录按历史快照展示，不能把旧记录当成更新后的最新数据。
