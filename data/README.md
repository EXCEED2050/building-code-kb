# 数据目录

- `catalog/`：文件台账、规则、校订记录、完整 PDF 映射、验收题、单份 PDF 下载索引。
- `chunks/`：受版本管理的 159 本原始条文 JSONL。
- `manifests/`：条文与大附件的大小、SHA256 和来源路径。
- `sources/`：本机 PDF、Word 与原始包，来自私有 Release，不进入 Git。
- `processed/`：需要保留的 MinerU、OCR 和完整阅读本，来自恢复或重建，不当作临时缓存。
