# 公开协作数据

本目录收录 16 本全文强制性工程建设规范的 2,033 个正文块，供项目协作、检索和解析开发。快照日期为 2026-10-19，正文及表格文本来自已有本地解析结果。

## 使用

从项目根目录运行：

```sh
python -m building_kb.commands.export_public --check
KB_CHUNKS=examples/public/chunks KB_CATALOG=examples/public/catalog.csv python run_dev.py
```

打开 <http://127.0.0.1:8000>，输入启动日志中的随机口令。可查询 `GB 55037 第1.0.1条`、`安全疏散`、`无障碍通道`。

命令行检索：

```sh
python -m building_kb.search.retrieve --chunks examples/public/chunks --no-rerank "GB 55037 第1.0.1条"
```

## 来源和筛选

`sources.json` 逐本记录编号、名称、政府来源和筛选日期；`manifest.json` 记录输出条数、字节数和 SHA256。`catalog.csv` 只保留公开编号、名称及来源，不包含本机文件路径和内部资料清单。

本次仅按经过核对的白名单选取全文强制性工程建设规范正文。筛选依据包括各规范的政府发布公告，以及市场监管总局[《强制性国家标准管理办法》解读](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/xwxcs/art/2023/art_41f9e74ec1184f799186a77bfb768031.html)对强制性国家标准属性的说明。此筛选不扩展到所有 GB 编号文件、推荐性标准、条文说明、国际标准或出版物扫描版。

导出工具不会更改正文、表格数值或原页码。全文强制属性依据相应公告标注，附原始来源。被替代、废止、条文说明及被解析器标为“修订”的部分均未导出；这批“修订”记录中发现了目录误识别，因此本次不把它们作为正式修订条文发布。

本目录没有收录企业标准、内部业务记录、原书图片、出版版 PDF、完整 OCR 文件或密钥，也没有给规范文本另加项目软件许可证。

## 数据边界

- 本快照不是官方标准发布渠道；未完成逐条 OCR 校对或截至当前日期的全部修订、废止核验，不能凭它直接确定工程设计要求。
- `page_idx` 沿用本地解析页码，未提供对应 PDF；不能保证与后来从其他网站取得的版本一致。页面“看原文”需要自行配齐并核验原件。
- `status` 保留本地台账状态，可能为 `待核`，不要据此推断当前效力。
- `caveat` 明确标注开发快照的校验边界。回答和页面展示时应保留它。
- 需要完整内部数据时，应另行确定授权和受限共享方式，不能把此前生成的全量本地协作包放进公开仓库。

## 更新

具备完整本地语料的维护者可在逐本核对来源后修改 `sources.json`，从项目根目录运行：

```sh
python -m building_kb.commands.export_public
python -m building_kb.commands.export_public --check
```

其他协作者不需要私有语料即可运行 `--check`、浏览页面和使用公开条文。修改导出规则后，应连同白名单、清单和条文快照一起提交审阅。
